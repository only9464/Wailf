# ADR-0009：应用级全局数据

- 状态：`accepted`
- 日期：2026-09-20
- 替代：ADR-0002 早期边界方案

## 背景

Wailf 面向本机单用户，业务对象需要直接查询和跨入口共享。保留额外的数据容器会增加 DTO、查询参数和持久化结构的复杂度，并模糊全局历史追溯关系。

## 决策

- 采用本机单用户、应用级全局数据模型；Asset、Job、Artifact、Session 和 AuditEntry 直接查询。
- 资产按领域键在应用级去重，观测记录保留任务、来源和时间信息。
- 规则检查由应用级策略和领域服务负责，策略变化不改写历史结果。
- 业务数据、GUI 偏好和秘密引用分别存储，撤销配置不级联删除历史记录。
- 由于没有现存业务数据库，本次只修改未发布模型，不执行数据合并迁移。

## 后果

全局任务面板和资产查询无需上下文切换；扫描、连接和会话页面直接使用目标与功能参数。多用户或远程部署需要另行设计身份、并发和数据隔离策略。
