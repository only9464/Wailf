# ADR-0004：会话连接器边界

- 状态：`accepted`
- 日期：2026-09-19

## 背景

C2、WebShell 和 SSH 类连接与一次性扫描不同，具有心跳、双向 I/O、状态机和长期审计；但首期不应承担自研 Agent、载荷或植入流程。

## 决策

首期只定义外部 Session Connector。Session 统一生命周期、心跳、关闭、审计和远端摘要；命令、文件、交互终端是 Connector 声明的可选 SessionChannel。元数据和审计默认持久化，原始输出按会话策略和 TTL 保存。

Connector 是会话领域边界，不提升为所有能力的通用接口。默认入口不暴露任意远端命令执行。

## 后果

不同外部系统可以保留协议差异，同时 GUI 能以一致方式显示在线状态。连接器需要严格的凭据、超时、取消、清理和日志脱敏测试。

## 被否决方案

- 首期自研 Agent：跨平台、协议和安全范围过大。
- 只保存连接元数据：无法验证平台对持续会话的核心抽象。
- 首期把完整交互终端全部定死：会锁定尚未验证的产品细节。
